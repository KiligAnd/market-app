# 商品行情计价系统 · Vue + FastAPI + SQLite

由 `code/商品行情计价系统原型.html` 迁移而来的 Vue 3 工程，保留原有页面与视觉样式，并接入 WB00001 清远机生铝、WB00002 佛山黄杂铜真实行情。
FastAPI 后端已收进本工程的 `server/` 目录，数据库在 `data/market.db`。

物料编码分两类：网站物料用 `WB00001` 这类编码，公司系统物料用 `XT00001` 这类编码。
一个网站物料可对应多个公司系统物料，在「定价配置 → 物料计价规则」维护。

新增 **网站物料采集配置** 页面（`/collect`）：选择网站、输入网站物料名称、选择省/直辖市与市，搜索富宝产品后绑定网站物料。
配置写入 SQLite `source_material_configs`，每日同步和看板物料下拉都从该表读取，不再需要改 Python 代码。

## 网站物料采集配置

1. 打开「行情管理 → 网站物料采集配置」。
2. 筛选栏最左侧是「网站」下拉框，选中「富宝资讯」后其面板中有「用户账号」一项，点击后弹出登录弹窗：输入一次富宝用户名/密码，登录成功后凭据用 Windows DPAPI 加密保存到项目根目录 `cred.dat`（仅当前 Windows 账户可解密），token 过期后后端会自动用该账号登录刷新。
   手动 `AUTH_COOKIE` 入口折叠在弹窗的「使用 AUTH_COOKIE 临时登录（备用）」中（写入 `auth_token.txt`，无 BOM）；如果账号触发富宝风控/验证码，自动登录会失败并在弹窗显示原因，此时可用备用入口兜底。
3. 页面按网站区分：筛选栏最左侧的「网站」下拉用于切换网站，选中网站后显示该网站的总开关、物料数量、今日同步数、最近同步时间、用户账号和物料列表；不再提供「按网站 / 按物料」视图切换。
4. 网站总开关关闭后，其下物料全部不参与每日同步；单个物料开关只在网站启用时生效。
   每日同步对全部启用物料只发 **1 次批量请求**，物料越多也不会成倍消耗接口配额。
5. 选中网站面板内可「全部启用 / 全部停用」，下方物料列表可逐条切换物料开关。
6. 点击「新增采集配置」：网站下拉选择（当前支持富宝资讯）、输入网站物料名称、选择省/直辖市（**市可不选**，不选时按全省匹配）。
7. 点击「搜索富宝产品」，从候选表中选择产品（地区匹配的排在最前）。
8. 网站物料由系统**自动创建**（`WBxxxxx`，命名规则：市简称/省简称 + 物料名称），无需手工绑定。
9. 填写「初始回补天数」N 后，点击 **保存配置并同步历史数据**：保存成功后自动回补 `今天−N 天 ~ 今天`，每 60 天一个窗口；列表「历史回补」列实时显示 `同步中 x/y`。
10. **编辑配置时把天数调大**也会自动续补：按钮变为「保存配置并同步历史数据」，只补更早的差额窗口，不会重抓已有区间；调小只更新展示天数，不删除历史。
11. 配额不足时保存仍成功，提示「明日续跑」；列表行「回补」按当前配置天数继续补，「校验」重新拉取富宝产品信息。
12. 「物料信息映射表」只维护计价对照，不影响采集开关；采集开关以采集配置为准。

> 富宝搜索接口本身不按省市过滤，后端会按报价地区 `place` 做本地匹配，因此省市选择仍然必要。

## 物料信息映射表

- 数据源与「物料计价规则」同表（`material_pricing_rules`）：一行 = 公司系统物料 ↔ 爬虫采集物料，含固定调整值 / 调价系数。
- 新增映射 = 先选择网站，再从该网站下的网站物料中选择，然后绑定公司系统物料（XT）；批量导入格式：`系统物料编码, productId, 固定调整值, 调价系数`。
- 停用映射仅停止该系统物料计价，不影响行情采集；采集开关在「网站物料采集配置」。
- 系统物料清单当前手工维护，后续对接 BIP 物料接口后自动同步（`materials.source_type/bip_material_id/bip_code`，Phase 2）。
- 旧 `material_aliases` 表退役：仅保留作行情外键兼容，不再是映射页面数据源。

## 物料计价规则

- 物料编码分两类：网站物料 `WB00001` 起，公司系统物料 `XT00001` 起。
- 一个网站物料可对应多个公司系统物料，每条规则包含模板、固定调整值、调价系数、状态。
- 计算售价 =（上一完整周周均价 + 固定调整值）× 调价系数，结果保留两位小数；固定调整值 `0` 表示不增不减。
- 统计周期为周一至周日的完整周；周一至周五有报价，周六日无价格更新，只用周一至周五的报价计算周均价。
- 页面可对同一网站物料下的全部系统物料「统一调价系数」。
- 当前配置：
  - 清远机生铝（WB00001）→ 铝 `0`、轻杂铝 `-842`、铝质车底盘 `-4500`，统一系数 `1.03`；
  - 佛山黄杂铜（WB00002）→ 废电线 `-5800`、混铝铜废电线 `-11802`，统一系数 `1.18`。

访问富宝接口需要有效 token。token 过期时接口会返回 503，请先在项目根目录执行：

```powershell

```

## 按钮逻辑补齐情况

- **手动采集行情**：调 `/api/collect/run`，后台执行爬虫并增量导入 SQLite；
- **自动计价立即执行**：按「网站物料 → 公司系统物料」计价规则和上一完整周均价生成 `calc_runs` / `calc_results`；
- **映射新增 / 编辑 / 批量导入**：已接入 SQLite；
- **新增系统物料规则**：一个网站物料可配置多个公司系统物料，可统一本组调价系数；
- **计价结果明细 / 批次明细 / 执行日志**：已用真实数据补齐；计价结果管理默认按「本周（执行周）」展示，并新增「计价周」下拉筛选，可切换本周、上周、历史周或全部周；
- **导出定价报表**：支持按周 / 按月；周可选本周、上周、自定义周，月可选本月、上月、自定义月。导出为 `.xlsx`，按「品种经销价格推算」模板生成：类别、标的物、序号、品名、单位、周一至周五报价、网络平均价、固定系数、底标价、中标系数、执行价、浮动率来源；按月导出时每个执行周生成一个工作表；
- 原先只弹提示的“查询”按钮已移除，筛选条件保持实时生效。
- 行情台账改为后端分页：默认每页 10 条，可选 10/20/50/100，支持日期范围和关键词筛选，每页条数保存在浏览器 `localStorage`。
- 行情台账列口径：「价格」= 富宝报价区间（`raw_text`）；「当日平均价」= 当日区间中值（`avg_price`，两位小数）；「涨跌」= 当日涨跌文案；「采集时间」= 真实抓取时刻（`captured_at`），历史回补行没有逐行抓取时间，显示「历史回补」。
- 采集时间拆成两列：`captured_at` 只存快照拉取时刻（来自快照 CSV 的「抓取时间」），`imported_at` 存每次入库时间（批次级）。「今日采集行情条数」按 `quote_date = 今天` 统计，历史回补不会算进今天。
